# Amith Viswas Reddy – Portfolio

Welcome to the public repository of my personal portfolio – [amithviswas.github.io](https://amithviswas.github.io/) (or your live URL), built with [Astro](https://astro.build).

I am a Data Science student at Lovely Professional University, minoring in RPA. This portfolio showcases my journey, projects, and skills in Data Science, Machine Learning, and Robotic Process Automation.

## 🚀 Getting Started

To run the project locally:

```bash
# 1. Clone this repo
git clone https://github.com/amithviswas/AW-2025-Portfolio-main.git
cd AW-2025-Portfolio-main

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```
